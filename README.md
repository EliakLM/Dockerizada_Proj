## 📋 Visão Geral
Aplicação web containerizada com:
- **Nginx** como balanceador de carga
- **PHP** para processamento backend
- **MySQL** para armazenamento de dados
- **Docker Compose** para orquestração

## 🚀 Como Executar

### Pré-requisitos
- Docker 20.10+
- Docker Compose 2.0+
- 2GB RAM disponível
